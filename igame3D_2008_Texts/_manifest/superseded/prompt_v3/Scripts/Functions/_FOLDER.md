# Data/Scripts/Functions
- **Role:** This folder holds the Lua 5.1 script libraries, engine-core helpers, and tool routines for the 2008 iGame3D 3D game engine, built on murgaLua, FLTK, and LuaFileSystem. It provides reusable functions for animation, camera, material, mesh, particle, and UI handling used across the game's levels and demos.
