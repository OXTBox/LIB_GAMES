# Data/Fluid/CameraBrowser
- **Role:** This folder holds the FLTK user interface for the iGame3D CameraBrowser, a dialog that lets a programmer browse and edit camera sources, attributes, values, and materials through FLTK widgets and callback handlers. It defines the window, its groups and controls, and the Lua callbacks that wire those widgets to the engine's camera data.
- **Entry point:** CameraBrowser.lua
- **Files:**
  - CameraBrowser.fl - FLTK user interface definition for the CameraBrowser dialog, defining the window, groups, controls, and Lua callbacks that wire widgets to engine camera data.
  - CameraBrowser.lua - Lua implementation of the CameraBrowser UI, managing camera tool groups, value and attribute list browsers, save/replace UI, and running the FLTK event loop to display the dialog.
  - script.fl - FLTK user interface designer data file for the CameraBrowser fluid UI, defining the camera browser window, groups, value inputs, menus, and callback logic for browsing and editing cameras.
