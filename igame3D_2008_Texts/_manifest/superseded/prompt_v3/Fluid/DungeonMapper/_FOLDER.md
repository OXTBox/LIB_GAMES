# Data/Fluid/DungeonMapper
- **Role:** This folder holds the DungeonMapper tool, a FLTK-based user interface for editing and converting dungeon maps in iGame3D. It lets a programmer draw or erase map elements on a grid, browse maps, manage dungeon tool options, and save mapped maps back to DSB or mesh files.
- **Entry point:** DungeonMapper1226830pm.lua
- **Files:**
  - DungeonMapper.fl - FLTK UI designer source for the DungeonMapper tool window, map browser, tool browser, and save window widgets with callbacks.
  - DungeonMapper.lua - DungeonMapper tool script that loads map data from DSB text files, edits map elements on a grid, and saves mapped maps to DSB or mesh files.
  - DungeonMapper1226830pm.fl - FLTK user interface designer file for the DungeonMapper tool defining window, browser, grid editing, and map text window widgets.
  - DungeonMapper1226830pm.lua - Main tool script for the DungeonMapper that wires up map browser, grid editing, DSB dungeon conversion, and tool options, then runs window and menu setup.
  - DungeonMapperwModels.fl - FLTK user interface designer file for the DungeonMapper tool (models referenced by the tool).
- **Shared with other folders:** The tool depends on `Data/Scripts/Convert/DSB_Dungeons.lua` and `Data/Scripts/Convert/DSB_global.lua` for DSB dungeon conversion logic, uses `Data/Levels/` via `loadLevel` to switch levels, and references `Data/WTF/Dungeons/` for map files. It also relies on engine calls and globals from the iGame3D engine (e.g., `gObjects`, `make`, `get`, `loadLevel`, `dofile`, `lfs.dir`, `fltk`, `murgaLua.`).
