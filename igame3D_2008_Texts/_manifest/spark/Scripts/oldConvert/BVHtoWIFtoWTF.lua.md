## BVHtoWIFtoWTF.lua
- **Kind:** converter
- **Purpose:** This file provides conversion functions that translate BVH animation data into WIF and then into WTF animation text files for iGame3D. It documents the ordered steps for the BVH-to-WIF-to-WTF conversion workflow and contains the functions that perform the actual file conversions.
- **Depends on:** `Data/BVHPathTables.lua`, `Data/WIFPathTables.lua`, `Data/WIF/` folder, `Data/WTF/` folder, `Data/WTF/WIF/` folder, `truebonesbvh_parser.lua` (loaded via absolute path), globals `BVHtoWIF`, `BVHTables`, `gFrameTime`, `gObjects`, and engine functions `getObjectInfo`, `ig3d_GetObjectBonesList_s_s`, `ig3d_GetObjectBoneInfo_2s_6f`.
- **Provides:** `createBVHPathTables`, `recreateWIFPathTables`, `sortBVHWIFTables`, `convertBVHtoWIF`, `WTFNoAnimFile`, `convertWIFtoWTF`.
- **Assets it needs:** none (no models, images, sounds, emitters, or fonts are named in this file).
- **Procedural:** yes - generates BVH path tables, WIF path tables, sorted animation lookup tables, and WIF-to-WTF animation text files from existing BVH/WIF source files and folder structures.
- **Glossary:**
  - BVH - a motion capture animation file format used by iGame3D for 3D animation data.
  - WIF - a text format for storing animation data that is converted to WTF for iGame3D use.
  - WTF - a text format for 3D model and animation data used by iGame3D.
  - BVHTables - a Lua table mapping BVH animation names to their saved file paths, generated by the file.
  - WIFTables - a Lua table mapping animation names to their saved WIF file paths, generated by the file.
  - WIF animation WTF file - a WTF file created from WIF animation data for use in iGame3D.
- **Keep / port / drop:** keep - it is a reusable conversion tool with clear, ordered steps for translating BVH animation data into WTF for iGame3D.
