# Data/Scripts/oldConvert
- **Role:** This folder holds two converter tools for iGame3D: one translates BVH motion capture data into WIF and then into WTF animation text files, and the other converts FLUID-generated C++ source files (including FLUID UI files) into iGame3D Lua code. Both are reusable conversion utilities for building engine assets from external sources.
- **Entry point:** none
- **Files:**
  - BVHtoWIFtoWTF.lua - converter that provides ordered BVH-to-WIF-to-WTF conversion functions and path table generation for iGame3D animation data.
  - cxxToiGame3DLua.lua - converter that parses FLUID/C++ source files, validates inputs, redirects file loading, and rebuilds the Mac menu bar after fluid conversions.
- **Shared with other folders:** BVHtoWIFtoWTF.lua depends on Data/BVHPathTables.lua, Data/WIFPathTables.lua, the Data/WIF, Data/WTF, and Data/WTF/WIF folders, truebonesbvh_parser.lua (loaded via absolute path), and engine functions getObjectInfo, ig3d_GetObjectBonesList_s_s, ig3d_GetObjectBoneInfo_2s_6f. cxxToiGame3DLua.lua depends on Data folder paths for source and generated Lua files, Scripts folder for FLUID conversion helpers, and background engine references such as loadLevel.
- **Procedure candidates:** BVHtoWIFtoWTF.lua generates BVH path tables, WIF path tables, sorted animation lookup tables, and WIF-to-WTF animation text files from existing BVH/WIF source files and folder structures. cxxToiGame3DLua.lua generates Lua source files from FLUID .fl files and C++ .cxx files by parsing source content and applying conversion rules to produce output text.
- **Glossary:**
  - BVH - a motion capture animation file format used by iGame3D for 3D animation data.
  - WIF - a text format for storing animation data that is converted to WTF for iGame3D use.
  - WTF - a text format for 3D model and animation data used by iGame3D.
  - BVHTables - a Lua table mapping BVH animation names to their saved file paths, generated by the file.
  - WIFTables - a Lua table mapping animation names to their saved WIF file paths, generated by the file.
  - FLUID - the UI designer whose .fl files are converted to Lua.
  - CXX - C++ source files that are converted into iGame3D Lua code.
  - dofile - Lua file loading function that is overridden by this converter to route conversions.
  - ig3d_RebuildMacMenubar - engine call used to rebuild the Mac menu bar after fluid conversion.
- **Verdict:** keep - both files are reusable conversion tools with clear, ordered steps for translating external sources (BVH/C++/FLUID) into iGame3D assets, and no assets or behavior need to be dropped.
