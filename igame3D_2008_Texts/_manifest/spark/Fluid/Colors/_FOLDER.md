# Data/Fluid/Colors
- **Role:** This folder holds the FLTK-based color editing UI for iGame3D, letting players adjust scene, light, fog, and tint color attributes through a color input window, color chooser, and fog toggle controls. It is shared by the color editing tool files in the Fluid folder and provides reusable color editing logic for new iGame3D color interfaces.
- **Entry point:** Colors.fl
- **Files:** Colors.fl - FLTK user interface file defining the color editing window layout, color input and toggle widgets, and embedded code blocks driving color and fog editing; Colors.lua - Lua implementation of the color editing interface, loading the color source texture and managing the color edit workflow; Colors.lua - duplicate color editing interface implementation with the same setup, display, application, and event handling logic; MikColors.lua - top-level UI setup for the color editor defining the color map and color chooser buttons with their callback logic for applying color choices.
- **Shared with other folders:** Needs `Data/Images/Colors/colorsource.png` (color source texture) from the Images folder; depends on engine calls such as `getSceneInfo`, `setSceneInfo`, `getLightInfo`, `setLightInfo`, `ig3d_SetBackgroundColor_3f`, `ig3d_SetGridColor_3f`, `ig3d_GetColorInTexture_s6i_4f`, and constants `IG3D_AMBIENT`, `IG3D_DIFFUSE`, `IG3D_SPECULAR`, `IG3D_BACKGROUND_COLOR`, `IG3D_FOG`, `IG3D_TINT_COLOR` from the engine; shared globals include `gColorEditMode`, `gColorAttribute`, `gColorTargets`, `gChosenLight`, `gRed`, `gGreen`, `gBlue`, `gAlpha`, `gfogEnabled`, `gFogstart`, `gFogend`, `gFogEnabled`, `gLabelTable`, `gEditingMode`, `colorswindow`, `colormap`, `w`, `toggleAmb`, `toggleDif`, `toggleSpec`, `Rfld`, `Gfld`, `Bfld`, `showColorChooser`, `displayColorAttribute`, `applyColor`, `colorBtnClicked`, `handleColorInput`, `colorFromSource`, `color_event_callback`, `MaxOfOne`, `colorChooser`, `left`, `bw`, `row`, `pop`, `color_o`, `k`, `hexcolor`, `tCount`, `texFile`, `wleft`, `wtop`, `wright`, `wbottom`, `quote`, `gColorEditMode`, `gColorAttribute`, `gColorTargets`, `gChosenLight`, `gRed`, `gGreen`, `gBlue`, `gAlpha`, `gfogEnabled`, `gFogstart`, `gFogend`, `gFogEnabled`; others take the color editing UI and logic from this folder.
